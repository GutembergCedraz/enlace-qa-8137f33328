Como usar e como levar para o Jira
  1. Use Iniciar, Concluir e Reabrir nos cartões, ou arraste o cartão entre as colunas.
  2. Tarefa com faixa vermelha está bloqueada: ela só pode ser iniciada quando todas as tarefas de que depende estiverem como Feita. Faixa verde indica que já pode começar.
  3. O status fica salvo neste navegador. Para passar para outra pessoa, use Salvar status (.json) e ela usa Carregar status.
  4. Para importar no Jira: Exportar CSV para o Jira → no Jira, Configurações do sistema → Importação externa do sistema → CSV. Mapeie Issue Id, Summary, Issue Type, Status, Priority, Labels, Description e Parent; as colunas Blocked by viram o vínculo “is blocked by”. Os status do arquivo são To Do, In Progress e Done.
